# Repository routing

- This directory contains the TX WebApp and belongs only to `https://github.com/EPIIIC/VNS_TX_APP.git`.
- Never push this directory to the legacy `VNS-Webapp` repository.
- Future WebApp changes accompanying TX/RX firmware must continue to be pushed to `VNS_TX_APP`.
- Do not commit `node_modules`, generated `dist`, or local `verification` artifacts.
